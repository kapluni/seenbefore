# viz_examples

Standalone prototypes of corpus-level visualizations and statistical
validation artifacts. **Not wired into the UI** — these are reference
outputs produced from the same data the site uses.

| File | What it is | Source data |
|---|---|---|
| `run_stats.py` | Computes permutation test, Cohen's d, bootstrap CI, ROC/AUC, Mann-Whitney on 24 curated matches vs. 8 legitimate-criticism texts, 10 known echoes, and 1,000 random Soviet–modern pairs | embeds full Soviet (1,943 filtered passages) + modern (2,000 sampled) corpora via BGE-large |
| `stats_data.json` | Raw score arrays + all derived statistics (committed so downstream scripts don't need to re-run the full embedding pipeline) | output of `run_stats.py` |
| `ridgeline.py` → `ridgeline.png` | KDE ridgeline of cosine-similarity distributions across the four reference groups, with Youden threshold line and calibration overlay | `stats_data.json` |
| `arc_diagram.py` → `arc_diagram.png` | Decade-gap arc diagram of the 24 matches, Soviet years on the left axis, modern on the right, arcs colored by shared trope and weighted by ensemble score | `viz_data.json` |
| `sankey.py` → `sankey.html` | Trope-flow Sankey: Soviet trope → modern trope, re-classified per match. Interactive Plotly; loads plotly.js from CDN so the file stays ~10 KB | `viz_data.json` + `embedding_pipeline.TROPE_TAXONOMY` |

## Running

```bash
# Full statistics run (~3 min: embeds Soviet + modern corpora once)
python viz_examples/run_stats.py

# Visualizations (fast, ~1 sec each)
python viz_examples/ridgeline.py
python viz_examples/arc_diagram.py
python viz_examples/sankey.py
```

`run_stats.py` must run before `ridgeline.py` (which reads `stats_data.json`).
`arc_diagram.py` and `sankey.py` only need `viz_data.json`, which is already
generated by the main pipeline.

## Why these three visualizations

Chosen from a broader survey (see session research memo) for this specific
"these arguments persist across decades" narrative:

- **Ridgeline** renders the calibration story at population level — propaganda
  distributions sit visibly right of legitimate criticism and far right of the
  random-pair null. The Methodology tab displays the same numbers as a stats
  grid; this is the distributional view of the same evidence.
- **Arc diagram** is the signature visual for the core thesis. The visible
  gap between the Soviet and modern eras is part of the argument: structural
  parallels across decades, not proven transmission.
- **Sankey** shows which Soviet rhetorical categories map to which modern ones.
  Rhetorically risky — Sankeys inherently imply directed flow, which we've
  disclaimed — so the subtitle states "rhetorical-category correspondence, not
  causal transmission."

Anti-patterns deliberately avoided: word clouds (reproduces slurs), naive
UMAP/t-SNE hero images (cluster shape is a hyperparameter artifact, per
Coenen & Pearce's *Understanding UMAP*), dense force-directed graphs (hairball
failure on this density).
